## Set the hierarchy

The user skims. They read the first words of each part. Those words alone must carry 80% of the answer.

Information hierarchy: the most important comes first (the inverted pyramid; Minto).

- Open with the whole point, in one sentence.
- Then the hazard, then the highest-leverage next change.
- Then one part per aspect. All parts are at the same level, never one inside another.
- Each part opens on its conclusion. The detail comes under it, if there is any.
- Say why and what before how.
- What you noticed in passing comes last, folded.

Visual hierarchy: size and weight tell the eye where to go first. On a map, the country's name is read before the city's.

- Put the whole point and the conclusion of each part in bold. Nothing else is bold.
- A conclusion is a full sentence that states the verdict: "The export drops the last row." "The export: one issue" is a label: it only says where to look.
- Mark a hazard with ⚠, before what it concerns. Use an emoji only on what really stands out.
